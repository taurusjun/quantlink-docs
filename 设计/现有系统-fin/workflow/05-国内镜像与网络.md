# 国内镜像与网络

## pnpm / npm

项目 `.npmrc` 已配置：

```ini
registry=https://registry.npmmirror.com
```

手动设置：

```bash
pnpm config set registry https://registry.npmmirror.com
# 或只对当前项目
pnpm config set registry https://registry.npmmirror.com --location=project
```

验证：

```bash
pnpm config get registry
pnpm install
```

## Playwright 浏览器

默认从 Microsoft CDN 下载。国内可加：

```bash
PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright \
  pnpm exec playwright install chromium
```

如果已经卡住，先终止进程再重试。

## Electron / electron-builder

项目 `.npmrc` 已配置：

```ini
electron_mirror=https://npmmirror.com/mirrors/electron/
electron_builder_binaries_mirror=https://npmmirror.com/mirrors/electron-builder-binaries/
```

或临时：

```bash
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ \
  pnpm --filter @quantlink-fin/desktop install
```

## Gradle / Maven

`settings.gradle.kts` 当前使用 `mavenCentral()`。国内可改为：

```kotlin
maven("https://maven.aliyun.com/repository/public")
maven("https://maven.aliyun.com/repository/gradle-plugin")
```

Gradle 发行包可通过镜像下载后放到 `.tools/`，或修改 wrapper 的 `distributionUrl`。

## Homebrew

Homebrew 的 ghcr.io 下载可能受 HTTP/2 影响。可优先使用 `tools/install_toolchain.sh` 直接下载 JDK/Gradle，不依赖 Homebrew。

## 注意

- 不要把私有仓库凭据写入 `.npmrc`
- 镜像不可用时回退官方源
- 提交前确认 `pnpm-lock.yaml` 与镜像无关
