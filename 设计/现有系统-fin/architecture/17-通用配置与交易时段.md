# 通用配置与交易时段

## 1. 配置分层

```text
common_config_defaults
  全局默认

strategy_common_configs
  策略覆盖；没有记录时继承全局默认

strategy_pair_configs
  PAIR 私有参数
```

策略向导：

```text
PAIR:
  模板 → 两腿与价差 → 策略覆盖 → 部署

其他策略:
  模板 → 标的与期权链 → 报价参数与风险 → 策略覆盖 → 部署
```

`策略覆盖`默认关闭；关闭时继承 `common_config_defaults`。也可以通过
「通用配置」页面单独编辑某个策略的覆盖。

## 2. 通用执行/风控

```text
SIZE
MAX_SIZE
BID_SIZE / ASK_SIZE
BID_MAX_SIZE / ASK_MAX_SIZE
MAX_QUOTE_LEVEL
SUPPORTING_ORDERS
MAX_ORDERS
MAX_TRADED_QTY
CROSS
SLOP_TICKS
MAX_OPEN_ORDERS
MAX_LOSS / UPNL_LOSS / STOP_LOSS
收盘前停止(分钟)
收盘前强平(分钟)
```

下单控制面 `StrategyOrderService` 已执行：

```text
MAX_OPEN_ORDERS
MAX_ORDERS
MAX_TRADED_QTY
MAX_SIZE
MAX_LOSS / UPNL_LOSS / STOP_LOSS（按 strategy_daily_state.pnl）
```

runner 已执行：

```text
SIZE / MAX_SIZE（generic runner 下单数量）
SLOP_TICKS（PAIR）
HEDGE_SIZE_RATIO（PAIR 对冲比例）
收盘前停止/强平（PAIR runner）

控制面 StrategyOrderService 对所有策略 OPEN 单执行时段门禁：
  不在交易时段 → 拒绝 OPEN
  进入收盘停止窗口 → 拒绝 OPEN
  CLOSE 单允许，保证收盘后仍可平仓
```

仍未完全接入的 PAIR 高级语义：

```text
BEGIN_PLACE / LONG_PLACE / SHORT_PLACE
BEGIN_REMOVE / LONG_REMOVE / SHORT_REMOVE
HEDGE_THRES
CROSS / PIL_FACTOR / ABSPOS_THRES
```

## 3. 交易时段

```text
instrument_trading_sessions
  instrument_id
  session_type  DAY / NIGHT
  start_time
  end_time
```

默认值：

```text
CFFEX        DAY 09:30-15:00
其他交易所    DAY 09:00-15:00
SHFE / INE   NIGHT 21:00-02:30
DCE/CZCE/GFEX NIGHT 21:00-23:00
```

收盘停止/强平按当前时段结束时间减配置分钟数计算：

```text
SHFE 日盘 15:00 → 14:57 / 14:59
SHFE 夜盘 02:30 → 02:27 / 02:29
DCE  夜盘 23:00 → 22:57 / 22:59
```

交易时段可在「合约配置 → 时段」中维护。

## 4. SQL 规范

配置、订单、费用、日状态、交易时段链路已使用 MyBatis Mapper + XML。

新增 SQL 必须：

```text
backend/control-plane/src/main/resources/mapper/*.xml
```

不要再在 Controller/Service 中直接写 `JdbcTemplate` SQL。

历史模块仍有一批 `JdbcTemplate`，按模块逐步迁移。
