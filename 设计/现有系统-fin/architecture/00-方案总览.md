# quantlink-fin 方案总览

- 版本：v1.0
- 日期：2026-11-06
- 状态：已确认，进入 M0
- 目标：独立于 `quantlink-trading` C++ 实现，构建 Java + React + Electron 的期权/期货交易平台

---

## 1. 项目定位

`quantlink-fin` 是一个面向中国期货/期权市场的交易平台，分为：

1. **管理系统（Control Plane）**
   - 交易所/ORS 接入状态管理
   - 指标/策略配置与一键部署
   - 运行态监控、手工交易
   - 账号/资金/持仓/审计

2. **运行系统（Runtime）**
   - 实时行情 → 指标 → 策略 → 风控 → 下单/撤单
   - 支持期货 + 期权
   - 支持多品种、多交易所、多 ORS/账户

3. **交易所接入层**
   - New ORS Core（Java）
   - CTP Adapter（C++ 薄进程）
   - 通过 CTP SDK 连接盛立 CTP 柜台

详见：

强制要求：

```text

下单：runner 本地风控 → Aeron order stream

tick → 决策 p99 < 5ms
决策 → Aeron p99 < 1ms
热路径禁止 HTTP / JDBC / 同步写库
1 strategy = 1 agent
1 account = 1 agent = 1 ORS
策略持仓/PnL/收盘归属按 strategy_id + account + instrument
```

### 三种 Gateway 实现同一协议

| Gateway | 用途 | 数据源 |
|---|---|---|
| Replay Gateway | 策略验证/回测 | 历史 CSV/二进制/Chronicle |

| New ORS Core | 实盘/评测盘 | CTP Adapter → 盛立 CTP |

Runtime 通过配置切换 Gateway，不感知后端差异。

## 4. 运行系统

### 4.1 热路径

```
Aeron Subscription
   │ SBE 解码
   ▼
MarketData
   ▼
Indicator DAG
   ▼
Strategy
   ▼
Pre-trade Risk
   ▼
OMS
   ▼
SBE 编码 → Aeron Publication → ORS/Sim
```

### 4.2 Java 运行时规范

- Java 25 LTS
- 无 Spring、无反射、无动态代理
- Agrona `DirectBuffer` / `RingBuffer`
- 热路径零分配；价格 `long` 缩放，Greeks `double`
- ZGC Generational 或 Shenandoah
- `-Xms=-Xmx`、`AlwaysPreTouch`、大页
- `Thread.onSpinWait` + `BusySpinIdleStrategy`
- CPU 绑核（OpenHFT Affinity / taskset）
- 单 Shard 单 writer
- HDR Histogram + JFR + async-profiler
- 内部延迟目标：p99 < 100µs

### 4.3 模块

```
backend/runtime/
├── gateway/          # Aeron/SBE 连接
├── marketdata/       # 行情归一化
├── indicator/        # DAG/算子
├── strategy/         # 策略框架
├── option/
│   ├── pricing/      # BS/IV/Parity/Basis EMA
│   ├── greeks/
│   ├── portfolio/    # Delta/Vega/PnL/乘数
│   ├── quoting/      # 理论价/偏置/报价级别
│   └── hedging/      # 候选评分/IOC/被动
├── futures/          # 跨期/跨品种/趋势/TWAP
├── risk/
├── oms/
├── telemetry/
└── replay/
```

### 4.4 期货与期权

- 统一 `Instrument`：`FUTURE` / `OPTION`
- 期权扩展：underlying、expiry、strike、C/P、multiplier
- 期权链：underlying → call/put chain
- 期货是期权定价、Parity、Delta 对冲的基础
- 纯期货策略和期权策略共用 Runtime/OMS/Risk

## 5. New ORS 与 CTP Adapter

### 5.1 职责划分

| CTP Adapter（C++） | New ORS Core（Java） |
|---|---|
| CTP 登录/认证/结算 | 多交易所路由 |
| 行情订阅/回调 | Instrument Registry |
| 报单/撤单 | Order Router / OMS |
| 资金/持仓/合约查询 | Account/Position/Margin |
| 查询限流 | 风控前置 |
| 断线重连 | 审计/健康/指标 |
| CTP 字段映射 | 统一领域模型 |
| 交易所 offset flag（初期） | 多交易所规则（后期上移） |

### 5.2 接口

CTP Adapter 与 New ORS Core 通过 **Aeron IPC + SBE** 通信：

- `market-data`
- `order-request`
- `order-update`
- `trade`
- `account-snapshot`
- `position-snapshot`
- `gateway-health`

### 5.3 期权支持

- 收录 `ProductClass` 为期货/期权的合约
- 期权行情独立订阅
- 期权报单/撤单/持仓/保证金
- 期权链构建
- 行权/履约：首期不做，后续扩展

### 5.4 盛立柜台

- 使用 CTP SDK 连接盛立 CTP 前置
- 配置字段与 `quantlink-trading` 对齐：
  - `FRONT_ADDR_ORS`
  - `FRONT_ADDR_MD`
  - `PRODUCTION_MODE`
  - `BROKER_ID`
  - `INVESTOR_ID*`
  - `PASSWORD`
  - `AUTH_CODE`
  - `APP_ID`
- 如果盛立提供自有 SDK，则新增 `ShengliAdapter`，架构不变

## 6. 通信与 ABI

### 6.1 Aeron IPC + SBE

- 热路径统一 `aeron:ipc`
- SBE 负责零拷贝编解码
- Java/C++ 均使用官方客户端
- 不降级为 Unix Socket / 自定义 SHM
- Media Driver 独立进程，`/dev/shm/aeron`

### 6.2 SBE 消息

```
Instrument
MarketData
OrderRequest
OrderUpdate
Trade
AccountSnapshot
PositionSnapshot
GatewayHealth
```

### 6.3 版本与自检

- Schema 只追加字段，不删除/不重排
- 消息头带 schemaId/version
- 启动校验 schema version、stream id、Aeron channel
- 不匹配直接拒绝启动

## 10. 测试与数据

### 10.1 MVP 数据策略

实测结论（2026-11-06）：

- **期货**：190 上 `/home/u50_data/u50_*.csv` 为最新日数据，853 个合约，均为期货
- **期权**：`/data/u50_data/20260318/source/u50_20260318.csv`（9.5GB）**包含期权 tick**，样本如 `ad2604C26200`、`ad2604P18400`
- 因此 MVP 可以：
  1. 用 20260318 CSV 做**真实期权 replay**（需按合约过滤，文件很大）
  2. 用最新日期数据时，用 `SyntheticOptionChain` 生成模拟期权链
- **撮合**：`SimExchange`
- **后续**：CTP Adapter 录制更多真实期权 tick，逐步替换合成链
