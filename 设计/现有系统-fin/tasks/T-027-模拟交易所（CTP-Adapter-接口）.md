# T-027 模拟交易所（CTP Adapter 接口）

- 状态：DONE
- 阶段：M4
- 依赖：T-020, T-005, T-007, T-026
- 负责人：AI

## 1. 目标

在 CTP Adapter 的 CtpSession 接口下实现可配置的模拟交易所：基于真实回放数据加随机抖动，异步返回行情/报单/撤单/查询，行为尽量贴近真实交易所。

## 2. 范围

### 做

- SimulatedCtpSession 实现 CtpSession
- Replay 驱动的行情生成 + 随机抖动
- 价格-时间优先撮合、部分成交、排队
- 异步回调与随机延迟队列
- 报单/撤单/查询/资金/持仓模拟
- 拒单/断线/重连/限流故障注入
- 按交易所配置 tick/lot/乘数/涨跌停/交易时段
- 固定 seed 可复现

### 不做

- 不复刻交易所内部隐藏流动性
- 不复刻 CTP 二进制 wire protocol
- 不做真实结算/行权交割
- 不替代真实 CTP 联调

## 3. 交付物

- ctp-adapter/src/sim_exchange.h/.cpp
- sim-exchange.yaml 配置
- C++ 单元/集成测试
- 行为差异与限制报告

## 4. 设计要点

模拟器在 CtpSession 内运行；行情/回报走独立事件队列，按随机延迟投递；撮合价格-时间优先；配置驱动规则；固定 seed 可复现。

## 5. 验收标准

- [x] 模拟登录/订阅/报单/撤单/查询可用
- [x] 行情基于真实 tick 并可加抖动
- [x] 异步回报有可配置延迟
- [x] 限价/市价/FAK/FOK/DAY/部分成交行为可验证
- [x] 拒单/断线/重连可注入
- [x] 固定 seed 重复运行结果一致
