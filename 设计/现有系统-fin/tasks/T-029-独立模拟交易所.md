# T-029 独立模拟交易所（Sim Venue）与正式接入

- 状态：DOING（核心链路已落地；跨主机/长稳/双跑待环境）
- 阶段：M6
- 依赖：T-003 Aeron、T-020 CTP Adapter、T-027 Sim Exchange、T-028 执行域
- 负责人：AI
- 设计文档：`docs/architecture/19-独立模拟交易所与正式接入.md`

---

## 1. 目标

把 SimLocal 从“交易主机上的内置模拟器”升级为独立部署的模拟交易所：

```text
独立进程 / 独立主机
Aeron/SBE 正式接入
独立账本、journal、snapshot
Runner/Control Plane 视为正常 venue
不存在 simInprocess / HTTP tick 旁路
```

---

## 2. 范围

### 做

- Sim Venue Core（撮合、订单簿、账户、持仓、费用）
- Sim Venue Gateway（Aeron、SBE、session、fencing、fan-out）
- venue 级 journal / snapshot / replay
- 多账户账本模型（至少预留）
- `aeron:ipc` → `aeron:udp` 跨主机
- Control Plane venue registry / channel 配置
- Runner 直连 remote MD/execution
- 安全、观测、对账、故障注入、双跑切换

### 不做

- 真实 CTP wire protocol
- 公网暴露
- 完整交易所规则（集合竞价、行权、交割）
- 多地域容灾
- 真实资金/清算

   跨主机后行情用 multicast，订单/撤单用 unicast，
   回报/成交按客户端独立 unicast 或 fan-out 服务。
3. 测试策略、测试订单/成交/持仓已清理；
   ledger_entries / audit_log 作为追加式审计保留。
4. SimExchangeService 仅保留行情/本地 canary 用途；
   等 SimVenue 对账与故障注入完成后再评估删除。
