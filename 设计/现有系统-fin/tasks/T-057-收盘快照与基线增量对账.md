# T-057 收盘快照与基线增量对账

## 目标

把策略/账户持仓对账从“当前持仓 vs 全量历史成交”改为：

```text
收盘权威快照
  + 快照之后的新成交
  = 当前持仓
```

同时保留策略 `daily_init`、策略版本和部署版本，支持收盘审计与 Runner 重启恢复。
