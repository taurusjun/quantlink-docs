## 1. 目标

将当前“柜台/账户选择器 + 分散页面”升级为 **策略中心 V2**：

```text
策略是交易、持仓、PnL、订单、成交、风控的主对象
柜台/交易所/账户/ORS/Agent 是策略部署属性
订单/成交/持仓带策略归属
总持仓按账户汇总
手工单进入独立 MANUAL 交易簿
已部署策略不可迁移，只能 Fork
```

---

## 2. 范围

### 做

- Counterparty / Exchange / Account / ORS / Agent 分层
- Book / Strategy / MANUAL / UNASSIGNED 账本
- 策略版本、绑定四元组、Fork、部署生命周期
- 订单/成交/回报的策略归属
- SBE v2 与 CTP/ORS 映射
- 策略持仓、账户持仓、策略 PnL、账户 PnL
- 对账、未分配认领、手工簿
- 权限、审计、应急范围、LIVE/SHADOW
- 策略中心 UI、账户汇总、柜台健康
- 迁移、双跑、回归和证据

### 不做

- 真实 CTP 交易所规则扩展
- 跨柜台策略
- 多账户单 ORS
- 多地域容灾
- 真实资金清算

---

## 3. 实施原则

```text
1. 先数据/合同/权限，后 UI
2. 先归属/行情/对账，后策略 PnL
3. 先只读策略中心，后编辑/Fork/部署
4. 任何阶段不得用全局行情冒充柜台行情
5. 任何阶段不得静默 fallback 到其他柜台/ORS
6. 任何阶段不得用账户持仓校验策略平仓
7. 每个 Phase 结束必须有可回滚开关
```

## 6. Phase Gate

### Phase 1 Gate

```text
[ ] DB 迁移可回滚
[ ] Book/MANUAL/UNASSIGNED 独立
[ ] 权限默认拒绝 + 403
[ ] 行情键 (counterparty, exchange, instrument)
[ ] SBE v1/v2 分流
[ ] 一柜台一账户 / 一策略一 ACTIVE 约束
```

### Phase 2 Gate

```text
[ ] 两策略同合约成交可归属
[ ] 策略平仓 A=2/B=8 不越界
[ ] 账户快照 vs 策略+手工差异可见
[ ] 未分配可认领
[ ] 旧 ORS/fencing 被拒绝
[ ] 无有效路由 fail-closed
```

### Phase 3 Gate

```text
[ ] 策略详情只显示当前策略
[ ] 账户上下文卡片
[ ] 订单/成交默认今日且策略跳转带 ID
[ ] 顶部柜台选择器移除后 6 个页面一致
```

### Phase 5 Gate

```text
[ ] 已部署策略不能换 Agent/账户/柜台/ORS
[ ] 编辑生成版本，更新只能同 Agent
[ ] Fork 新策略不继承持仓/PnL/订单
[ ] 默认平仓升级；carry 升级需确认
[ ] 部署失败可回滚
```

### Phase 6 Gate

```text
[ ] 策略应急只影响当前策略
[ ] 账户/全局应急显式范围
[ ] LIVE 默认禁用，启用需审批/红色确认
[ ] 柜台/交易所健康可下钻
[ ] 迁移后无归属订单/成交为 0
```

## 7. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 行情键改造影响策略 PnL | PnL 串价 | Phase 1 完成前策略 PnL 显示“数据未就绪” |
| SBE v2 兼容问题 | 回报丢失/错归属 | 双写/兼容队列/旧消息拒绝 |
| 多策略共享账户 | 持仓/PnL 归属错 | Book + book_positions + 策略平仓校验 |
| 手工单污染策略 | PnL/排名错 | MANUAL Book、排除自动收盘 |
| Fork/版本迁移 | 旧仓无主 | 四元组不可变、Fork 不继承持仓、默认平仓升级 |
| 权限绕过 | 越权交易 | 服务端 AuthorizationService、403、审计 |
| 旧 ORS 回报 | 状态覆盖 | route/orderEpoch/fencing/FENCED |
| Phase 提前上线 | 假策略中心 | Gate 未过不得删除顶部/上线 PnL |
