# T-007 Sim Exchange（期货+期权）

- 状态：DONE
- 阶段：M1
- 依赖：T-002, T-003
- 负责人：AI

## 1. 目标

实现内部模拟交易所，支持期货/期权订单撮合、成交、拒单、持仓与资金。

## 2. 范围

### 做

- 订单簿（期货/期权）
- 限价/市价/FAK/FOK/DAY
- 撤单/改单
- 成交模型：触价/排队/部分成交/延迟
- 账户/持仓/保证金/手续费

### 不做

- 不模拟真实交易所全部规则
- 不做结算

## 3. 交付物

- sim-exchange 模块
- 配置
- Aeron gateway
- 撮合测试

## 4. 设计要点

确定性 seed；订单簿由回放行情驱动；可配置 fill/reject；支持 synthetic 行情。

## 5. 验收标准

- [x] 限价单可成交/挂单
- [x] 无流动性时正确拒单/挂单
- [x] 撤单/改单状态正确
- [x] 持仓/资金随成交更新
