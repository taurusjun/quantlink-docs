## 4. 已知限制

1. C++ Aeron 在当前 macOS 上通过放宽 CMake 版本要求构建；**生产 Linux（Rocky 9.8）仍需单独验证**。
2. 全天 9.5GB 文件用 `awk` 单遍统计；Java 解析器只在 100 行 fixture 上验证，未跑完整 25M 行。
3. SimExchange 是 P0 简化撮合，不含完整期权保证金、手续费、交易所规则。
4. SyntheticOptionChain 只验证链路与公式，不代表真实期权流动性。
5. 尚未接 CTP / 盛立柜台；CTP Adapter 是 M3 任务。
6. 尚未做 GUI/管理面。

## 5. Go/No-Go

**GO。**

理由：

- 热路径所需的 SBE + Aeron IPC 已用 Java/C++ 双向 100k 验证
- 回放/模拟期权/模拟撮合/影子库均可运行
- 端到端链路已打通
- 剩余风险主要是生产 Linux 构建和 CTP 细节，属于 M3/M4 范围，不阻塞 M1 Runtime
